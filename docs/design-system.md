# Yodev — design system

Yodev est un studio produit et développement compact. La cible est un prospect avec un problème concret ; le discours porte sur les livrables, les arbitrages et la méthode, jamais sur des logos ou résultats invérifiables.

- Ivoire `#F7F5F0`, graphite `#0C1117`, cobalt `#315EFB`
- Teal secondaire `#19A58F`
- Plus Jakarta Sans pour les titres, DM Sans pour le corps, Fira Code pour les détails techniques
- Rayon standard 12 px, ombres courtes, grille éditoriale
- Thème clair par défaut ; le sombre reste disponible

Les réalisations suivent : problème, rôle, contraintes, décisions, résultat vérifiable et limites. Les offres décrivent livrable, durée indicative, prérequis, fourchette et prochaine action. Le hero est visible au premier rendu et les animations respectent `prefers-reduced-motion`.
